9. Spin waves in disordered magnets

This example uses to_inhomogeneous and SpinWaveTheoryLarge to calculate the spectrum of Rb₂Mn$_c$Mg$_{1-c}$F₄, a disordered quasi-2D antiferromagnet. A Mn concentration $c < 1$ introduces random magnetic vacancies. Inelastic neutron measurements were reported in Cowley et al., Phys. Rev. B 15, 4292 (1977). Sunny models this data using spin wave calculations on very large supercells.

using Sunny, GLMakie

Model a single Mn layer using the lattice constants of the diluted crystal. Following Cowley et al., the model retains just the effective nearest-neighbor exchange $J = 0.72$ meV. A weak easy-axis anisotropy orients the spins normal to the layer, and reproduces the zone-center gap of pure Rb₂MnF₄.

units = Units(:meV, :angstrom)
latvecs = lattice_vectors(4.1457, 4.1457, 13.801, 90, 90, 90)
cryst = Crystal(latvecs, [[0, 0, 0]])
sys = System(cryst, [1 => Moment(s=5/2, g=2)], :dipole; dims=(2, 2, 1), seed=0)
J = 0.72
set_exchange!(sys, J, Bond(1, 1, [1, 0, 0]))
set_onsite_coupling!(sys, S -> -0.008*S[3]^2, 1)
randomize_spins!(sys)
minimize_energy!(sys)
Converged in 166 iterations

A helper function that builds an 80×80 supercell, converts it to_inhomogeneous, and calls set_vacancy_at! for a fraction $1 - c$ of random sites. These vacancies model substitution of non-magnetic Mg. A more complicated model could also modify the local couplings via set_exchange_at!, set_onsite_coupling_at!, and related functions.

function diluted_system(sys, c)
    sys_inhom = to_inhomogeneous(resize_supercell(sys, (80, 80, 1)))
    for site in eachsite(sys_inhom)
        if rand(sys_inhom.rng) < 1 - c
            set_vacancy_at!(sys_inhom, site)
        end
    end
    minimize_energy!(sys_inhom)
    return sys_inhom
end

Calculate $S(𝐪, ω)$ at various Mn concentrations $c$. SpinWaveTheoryLarge is optimized for large supercells such as this one. It uses the Lanczos method instead of direct matrix diagonalization to reduce computational cost to linear scaling in system size.

Undiluted, there is a single sharp magnon. With dilution, the long-wavelength magnon near the ordering wavevector M stays relatively coherent, while modes near the zone boundary become strongly damped. Simultaneously, flat $𝐪$-independent bands appear. These are localized excitations of spins with different numbers of magnetic neighbors. Near and below the percolation threshold $c = 0.592…$, the low-energy weight is dominated by finite clusters.

qs = [[0, 0, 0], [1/2, 0, 0], [1/2, 1/2, 0], [0, 0, 0]]
path = q_space_path(cryst, qs, 150; labels=["Γ", "X", "M", "Γ"])
energies = range(0, 8, 200)
kernel = gaussian(fwhm=0.3)

fig = Figure(size=(768, 600))
for (i, c) in enumerate([1.0, 0.9, 0.8, 0.54])
    sys_inhom = diluted_system(sys, c)
    swt = SpinWaveTheoryLarge(sys_inhom; measure=ssf_perp(sys_inhom))
    res = intensities(swt, path; energies, kernel, threaded=true, verbose=true)
    plot_intensities!(fig[fldmod1(i, 2)...], res; units, colorrange=(0, 8), title="c = $c")
end

Fig. 5 of Cowley et al. reports neutron intensity at Mn concentration $c = 0.54$ and temperature 4.0 K. Their RLU notation uses a √2×√2 magnetic cell whereby $(ξ, 0, l)$ maps to Sunny's $(ξ/2, ξ/2, l)$. At the magnetic zone boundary $ξ = 1/2$, the three peaks represent Mn²⁺ ions with 2, 3, and 4 magnetic neighbors. Toward the magnetic zone center $ξ = 1$ the fine structure fades, and the intensity grows and moves to lower energies.

sys_inhom = diluted_system(sys, 0.54)
formfactors = [1 => FormFactor("Mn2")]
swt = SpinWaveTheoryLarge(sys_inhom; measure=ssf_perp(sys_inhom; formfactors))
ξs = [0.5, 0.6, 0.7, 0.8, 0.9, 1.0]
energies = range(1, 8, 141)
kernel = gaussian(fwhm=0.6)
res = intensities(swt, [[ξ/2, ξ/2, 2.9] for ξ in ξs]; energies, kernel, kT=4.0*units.K, threaded=true)
